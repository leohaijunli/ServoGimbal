# 仅使用 STL 正式零件的打印验证流程

适用对象：本目录交付的 MKS-X8-HBL388 / GoPro HERO8 双轴云台。

当前为 LW1 减重版：只更新 01/02，其余 14 件可继续使用。若之前打印过旧 01/02，不能直接把旧版配合/刚度记录当作本版验收；本版要重新执行第六、八批相关检查。减材与保留区详见 [LIGHTWEIGHT_UPDATE.md](LIGHTWEIGHT_UPDATE.md)。

**本文件是待执行的实物验证计划，不是已打印通过的验收报告。** 交付版已完成的 CAD 数字检查见 `assembly_checks.json`、`quality_report.json`。以下实物结果均需打印后填写。

本流程只打印 `stl/` 中的 16 件正式零件，不使用其他目录的试片。**上一批验证通过，再打印下一批；失败先处理，不要把全部大件一次打印完。**

## 1. 打印顺序总览

```text
11、12 → 05、06、07 → 16 → 09、10 → 15、13、14 → 02、03、04 → 08 → 01
```

每件各 1 个。打印顺序按关键配合、耗材风险和验证依赖安排，**不等于最终总装顺序**；最终组装还须遵循 [README.md](README.md) 的安装路径。

| 批次 | 文件（均在 stl/） | 本批重点 |
|---|---|---|
| 1 | `11_Tilt_25T_Hub.stl`、`12_Tilt_Clamp_Collar.stl` | 花键、夹紧套、铜套、轴端止挡 |
| 2 | `05_Pan_25T_Hub.stl`、`06_Pan_Clamp_Collar.stl`、`07_Pan_Inner_Spacer.stl` | Pan 花键、长轴颈、两轴承内圈和隔套 |
| 3 | `16_Pan_Front_Mount_Bridge.stl` | 防转螺母槽、通孔、螺钉头凹位 |

| 5 | `15_Removable_Left_Support.stl`、`13_Left_Bearing_Cap.stl`、`14_Left_Inner_Spacer.stl` | 左轴承外圈座、外圈压盖、内圈顶帽 |
| 6 | `02_Pan_Bearing_Carrier.stl`、`03_Pan_Lower_Cap.stl`、`04_Pan_Upper_Cap.stl` | 两轴承外圈座、完整 Pan 支撑模块、工具通道 |

## 2. 开始前的准备与规则

### 实物与工具

- 真实 MKS-X8-HBL388 舵机；后期总装需要 2 颗。
- GoPro HERO8 Black，不加未计入尺寸的保护壳。
- Pan：SKF 61804-2RS1，20 × 32 × 7 mm，2 颗。
- Tilt：SKF 61800 **开式**，10 × 19 × 5 mm，1 颗。
- ruthex **RX-M2.5x5.7** 热熔铜套，不把任意 M2.5 铜套的外形当成相同。
- 螺钉、垫片及 M3 DIN934 螺母按 `BOM.csv` / `FASTENERS.csv` 准备。
- 卡尺、合适的铜套安装头、2 mm / 2.5 mm 裸长臂内六角钥匙；需要量化回差时另准备合适的角度或位移测量装置。

### 每批都遵守

1. 按交付 STL 的毫米单位和打印姿态导入；不要误把总装坐标网格当打印文件。
2. 试装件采用计划用于正式件的相同材料、喷嘴和切片参数。换材料、喷嘴或孔补偿后，相关配合必须重新确认。
3. 花键优先 0.2 mm 喷嘴、0.10–0.15 mm 层高；这只是起始建议，不是已验证打印参数。
4. 支撑不得填进花键开缝、齿形或难清理的轴承配合面。去除毛刺和支撑碎屑后再试装。
5. 轴承入座只对相应圈施力，不通过滚动体传递压装力；不用锤击。
6. 铜套在独立零件上热装，冷却后再试螺纹。不歪斜、不转动、不顶出、不出现明显鼓包或层裂。
7. 花键对齐齿相后应能轻推装入；**不靠轴心螺钉硬拉进去，不把齿形磨成光孔。**
8. 不以加大拧紧力来弥补错误配合。不使用未经试验的拧紧扭矩，不强行回驱舵机，不做堵转试验。
9. 尺寸不通过时，记录实测值并修改相关打印补偿或模型参数；不要整体缩放真实舵机模型，也不要随意缩放零件而改变连接孔距。

## 3. 第一批：11 + 12，先验证 Tilt 传动

### 打印与装配

- 打印 `11_Tilt_25T_Hub.stl` 和 `12_Tilt_Clamp_Collar.stl`。
- 12 需要 1 颗 RX-M2.5x5.7 铜套；11 本体不需要热熔铜套。
- 先检查 12 能套到 11 的圆柱外表面，开缝没有被切片填死。
- 对齐真实输出轴齿相，轻推 11 装入，再安装 12。
- 轴心使用 M3×8 **ISO7380-1**，夹紧套使用 M2.5×12 DIN912 和对应垫片。螺钉型号、头形不能随意替换。
- 轴心孔底余量来自 CAD，实机仍须核对可用螺纹深度；不能把螺钉顶底误认成轴套锁紧。

### 检查与通过条件

- [ ] 25T 齿形完整，没有糊齿、缺齿、裂纹或明显支撑残留。
- [ ] 不用螺钉硬拉，轴套可以正常就位。
- [ ] 轴心螺钉锁紧后，轴套没有碰擦舵机的静止凸台 / 外壳。
- [ ] 夹紧套开缝能够收紧，没有先完全闭合却仍松动。
- [ ] 铜套不转动，夹紧耳不裂，不靠过度拧紧获得暂时固定。
- [ ] 用小力检查时无明显接口松动；量化回差结果另行记录。

当前 CAD 名义凸台间隙为 0.30 mm，完整齿形啮合下界为 5.40 mm，未夹紧几何空行程约 1.7°。**这些不是实物测量结果。**

手感晃动可能包含舵机内部齿轮回差和打印件弹性。只有可靠观察到轴套与真实输出轴之间的相对运动，才能归因于花键接口；无法分离时记录“来源未分离”，不要强扭输出轴进行区分。

第一批不通过，暂停后续打印。

## 4. 第二批：05 + 06 + 07，验证 Pan 轴套和内圈配合

### 操作

1. 打印 Pan 轴套、夹紧套和内圈隔套。
2. 检查 05 的花键与真实舵机轴、06 与 05 的夹紧配合。
3. 将两颗 61804-2RS1 的内孔分别轻套到 05 的长轴颈上；检查不同高度处是否同样合适，不能只检查入口。
4. 检查 07 的孔能套过轴颈，端面平整，隔套只作用于内圈，不碰密封圈或外圈。
5. 本批可做轻配合试装，不在没有外圈座固定的状态下做承载或运动验收。

### 通过条件

- [ ] 长轴颈没有明显椭圆、锥度、弯曲或象脚干涉。
- [ ] 两颗轴承都能正确套入，无明显径向松摆。
- [ ] 07 能就位，端面无毛刺；名义长度 9 mm，实测另填。
- [ ] Pan 花键和夹紧套满足第一批同样的配合条件。

名义轴颈 Ø19.98 mm，轴承内孔 Ø20 mm。**本批通过不代表 02 的 Ø32.1 mm 轴承外圈座通过。**

## 5. 第三批：16，验证防转螺母与紧固孔

### 操作

- 打印前耳安装桥，清理防转螺母通道。
- 用实际 M3 DIN934 螺母验证滑入、就位和防转。名义螺母 AF5.5 / 厚2.4 mm，槽宽 AF5.8 mm。
- 检查 M3 通栓、M2.5 通孔及头部凹位；螺钉应正常通过，不靠钻偏或强压。
- 16 **没有热熔铜套孔**，不能用它判断 PETG 铜套底孔已通过。

### 通过条件

- [ ] 螺母可从通道放入并对准孔轴，拧螺钉时不跟转。
- [ ] 通孔、凹位和桥体没有明显层裂或薄壁缺失。
- [ ] 与真实安装耳试贴时不挤压舵机壳体。

此时 01 尚未打印，只是孔槽 / 贴合初筛，**不做安装桥承载验收**。

## 6. 第四批：09 + 10，验证相机与笼架

### 操作

1. 打印笼架与顶压条，清理支撑；保护轴颈和连接面不被清理工具损伤。
2. 独立热装 09 的铜套，检查左轴颈可套入实际 61800 内孔。
3. 在支架外把 11 与 09 用四颗 M2.5×6 预装连接；**连接这四颗螺钉时先取下 12，不能等装上夹紧套和舵机后再找工具通道。**
4. 折叠 HERO8 安装脚，从上方放入相机；加可压缩防滑垫后安装 10。
5. 轻检查握持、镜头 / 屏幕、按钮及拆装。首次只做静态试装。

### 通过条件

- [ ] 相机不需要强压或掰笼架才能放入、取出。
- [ ] 夹持后不明显滑动，不挤压镜头、屏幕或按钮。
- [ ] 11 / 09 的贴合面贴合，四颗螺钉能正常紧固，没有头部干涉。
- [ ] 左轴颈与实际轴承内孔合适，无明显松摆。
- [ ] 上压条、铜套及连接板没有裂纹或明显翘曲。

相机官方外廓 66.3 × 48.6 × 28.4 mm，左轴颈名义 Ø9.98 mm。按钮避让只是设计保留区，实际触达要自行核对；电池门 / USB 使用可能需要取出相机。

## 7. 第五批：15 + 13 + 14，验证左轴承支撑

### 操作

1. 打印可卸左支架、外圈压盖和内圈顶帽。
2. 检查 14 的短止口完整；此处径向壁约 0.9 mm，不得缺线、开裂。
3. 在 15 上独立安装铜套，再试轴承外圈入座。名义外圈座 Ø19.1 mm。
4. 结合 09 的左轴颈，预装轴承、13 和 14，检查接触对象：**13 固定外圈，14 作用于内圈。**
5. 测自由转动时先脱开舵机花键，仅在轴承上轻转；不可通过强行回驱舵机判断轴承阻力。

### 通过条件

- [ ] 外圈可就位，无明显松摆，不需锤击。
- [ ] 紧固压盖 / 顶帽后没有明显新增阻力、擦碰或卡滞。
- [ ] 14 未先顶住轴颈端面而导致内圈无法被约束；CAD 名义端部余量 0.45 mm，实物另查。
- [ ] 铜套、轴颈、支架及顶帽没有裂纹或异常变形。

08 尚未打印，本批不能证明左支架与转台的最终定位及整机同轴性已经通过。

## 8. 第六批：02 + 03 + 04，验证完整 Pan 轴承模块

### 操作

1. 打印轴承座和两个压盖；清理内部台阶、桥接和深工具孔。
2. **此时才第一次验证 02 的两个 Ø32.1 mm 外圈座。** 两处分别试，不以一个孔合适代替另一个。
3. 结合第二批零件：下轴承从下方入座并装下压盖；隔套从上方放入；上轴承再入座。
4. 上压盖先套在 05 上，再穿入轴套、装下方夹紧套；经法兰四个工具孔紧固上压盖。
5. 尚未与舵机啮合时，轻转模块，检查径向松摆、轴向窜动和阻力变化。

### 通过条件

- [ ] 两个外圈座均可正确入座并固定，无明显松摆。
- [ ] 压盖只约束外圈，隔套 / 夹紧套只作用于内圈。
- [ ] 调整后无明显窜动且能顺畅转动，不靠强预紧消除间隙。
- [ ] 真实长臂钥匙能进入上压盖工具孔和底座连接深孔。
- [ ] 深孔、轴承座、台阶及铜套周围无打印缺陷。
- [ ] LW1 中心环座、四个孔柱和斜肋没有缺线、层裂或连接板桥接塌陷；支撑可清理，不损伤轴承配合面。

## 9. 第七批：08，验证独立 Tilt 预装

### 操作

1. 打印转台 / 右支架，独立热装铜套，先检查与 05 的连接、与 15 的定位柱 / 螺钉孔配合。
2. 固定 Tilt 舵机安装耳；用 M3 通栓与防转螺母，不借用舵机壳体螺钉。
3. 暂不安装 15，向右套入已预装的笼架 / 轴套组合。
4. 相机取出，经笼架右侧中心工具孔拧轴心螺钉，再检查夹紧套。
5. 不带轴承的 15 抬高约 2.2 mm，从左侧滑入再下落定位；装左轴承、13 和 14。
6. 先检查静态安装、工具接近、连接面和可见擦碰。没有确认供电、控制器和实际舵机行程前，不进行通电运动试验。

### 通过条件

- [ ] 不掰弯支架、不锤击、不强迫舵机轴即可按规定路线装入。
- [ ] 左支架定位柱和四颗连接螺钉正常就位，贴合面不悬空。
- [ ] 轴颈与两侧支撑对位，连接件紧固不造成明显新增阻力。
- [ ] 轴心、夹紧套和安装耳螺钉有实际工具空间。
- [ ] 空载可见连接无松动、擦碰或明显变形。

**独立预装不等于最终装配顺序。** 第八批整装时需要按 README 先完成 Pan 模块、08 / 05 连接，再安装笼架模块；必要时拆下第七批的预装模块，不能因已装好而跳过工具空间限制。

## 10. 第八批：01，正式整机组装与低载验证

### 装配检查

1. 打印底座并安装铜套、防转螺母，先检查桌面落地平整。
2. 16 暂不安装：Pan 舵机从上方放入开放底座；接插件通过通道后，再滑入 16 承托安装耳。
3. 用四颗 M2.5×10 固定安装桥，再用 M3 通栓 / 垫片固定安装耳。
4. 安装 Pan 轴承模块，经深工具孔紧固，检查轴心止挡、夹紧套和壳体间隙。
5. 先固定 08 到 Pan 法兰，再装 Tilt 模块、左支架及轴承；相机最后放入。
6. 桌面固定件的长度按实际基板选择。检查线缆松弛环，不把接插件当限位或拉力承受件。

### 通过条件

- [ ] 接插件不被挤压，舵机安装耳有承托，桥体与底座贴合。
- [ ] 轴心螺钉不顶孔底，轴套不碰静止舵机凸台；不靠摩擦外壳获得固定。
- [ ] 紧固件可接近，铜套不转动，连接面不悬空。
- [ ] 底座放置稳定或已可靠固定，无翘脚。
- [ ] LW1 格窗周围筋、桌面螺钉台、安装柱及安装桥承托完整，无塌线、裂纹或可见新增变形。
- [ ] 真实线缆不夹入、拉紧或挂碰结构。

### 运动与载荷检查

- 电压、针脚和控制器设置按真实 MKS 资料确认；本流程不提供猜测的电气接线。
- 先不装相机，从小角度、低速度、低加速度开始；确认无异常后才逐步扩大。
- 只有实际舵机和控制器允许时才扩大行程。CAD 的 ±90°、每 5° 检查不是实机行程保证，也不包括线缆。
- 空载正常后再装 HERO8 做低速、低载试验，观察底座稳定性、夹持、振动、松动和异常温升。
- 异响、卡滞、明显电流增加、发热、层裂、铜套转动或线缆拉紧时立即停机。
- **不做满堵转扭矩试验，不把一次低载运动成功写成长期强度 / 精度验收。**

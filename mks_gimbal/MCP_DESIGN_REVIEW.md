通过 MCP 实际读取了场景、对象层级、面引用顶点的世界包围盒、已确认 CAD 基准下的舵机轴线，并查看多角度图和底部 X-ray 图。没有改原模型几何，没有进行 FDM、强度或精度验收。

## 结论

**减重前版本是支撑和安装路线较保守的试配原型，底部的体积与装配复杂度偏高。** 外部轴承、宽法兰和正确花键限位有设计作用，但更多零件不自动等于更高精度或更可靠。

## 主要发现

### 1. 底部占用了大部分打印体积

复用已验证的 CAD 净实体体积：

- 01 底座：359,114.39 mm³。
- 02 Pan 轴承座：192,143.97 mm³。
- 全部打印件：779,678.29 mm³。
- **01 + 02 占 70.7%。**

这些是模型净实体体积，不是切片后的耗材量或实际重量。即便采用低填充，外壁、台阶与支撑的打印成本仍需实际切片确认。

优先优化方向：减少底座和轴承座的非承载实体体积，考虑保留受力路径的环座 / 支柱 / 肋结构；必须保留安装耳承托、轴承座、铜套周壁、定位和工具空间，并重新验证。不能直接抽空后宣称强度不变。

### 2. Pan 支撑与驱动分件过多

- 02～07 共 6 个打印件组成外部支撑 / 驱动模块。
- 若加上 01 和 16，底部区域共 8 个打印件，不含 U 形臂。
- 依据现有紧固件清单，底部相关装配（包括安装桥、压盖和转台连接）使用 26 颗螺钉。

双轴承支撑、宽法兰与夹紧 / 轴向限位的作用明确。问题主要是体积、分件和固定件数量偏多，而不是这些功能完全无用。

优先减少不必要拆分和堆叠高度；合并前须核对打印方向、轴承安装入口、热熔工具和拧紧路径。**不能随意删掉隔套 / 压盖，也不能未经核验用单颗薄壁深沟轴承替代有间距的双支撑。**

### 3. 精度瓶颈需要实物验证

当前 25T 侧隙放大量为 0.06 mm，未夹紧 CAD 几何空行程约 1.7°。Pan 轴颈 Ø19.98 对轴承内孔 Ø20 的名义直径差仅 0.02 mm，FDM 不能自动保证这种配合。

应先控制花键夹紧后回差、轴颈 / 轴承座打印误差、同轴性和轴向窜动，再判断外部支撑带来的收益。MCP 不能从截图或包围盒推导实际刚度、寿命或舵机侧载能力。

### 4. 原场景不是运动装配树

原总装只有 Model_Root、HERO8_Fit_Model 两个空对象，打印件未建立机构运动约束。直接旋转某个网格原点，可能产生错误运动，不能将其作为机构运动验证。

后续在 **独立动画副本** 中建立了 Pan/Tilt 虚拟轴，按 assembly_group 属性驱动定子、输出轴、打印件和紧固件。中位矩阵回到原位置、网格数据不变，不修改原始总装。

### 5. 展示复制件有未使用顶点

舵机的定子 / 转子展示网格各存有 31,577 个顶点；实际面使用的顶点分别约 27,939 和 3,817。显示分组保留了无面引用的顶点，会影响 Blender 的普通包围盒和自动取景。

这不代表原始舵机表面变形，也不代表打印 STL 存在这些问题。若清理，应只清理展示复制件的无用顶点，保留完整原始参考网格与实际面坐标。此次未做清理。

## 验证边界

复用了交付版网格、离散 ±90° / 每 5° 干涉检查、安装路线、工具通道和轴端止挡报告，没有另做同类 CAD probe。此次 MCP 检查确认现场场景与这些基准一致，但没有新增连续全姿态碰撞、FEA、切片、实物承载或夹紧精度验证。

建议优先级：**减轻 01 / 02 的非承载体积 → 在保证安装与打印路径的前提下减少分件 → 建立正确运动层级 → 做实际花键 / 轴承配合与低载试验。**

# 6200RS 少重打版 · STL 实物验证流程

本文件是**待执行的实物计划，不是打印通过报告**。数字检查见 `assembly_checks.json` / `quality_report.json`。

## 先分清需要打印什么

仅打印 `reprint_only/stl/` 的8种文件：

```text
17、07、14、18（3个） → 05 → 15 → 09 → 02
```

01、03、04、06、08、10、11、12、13、16复用原LW1打印件。不要因为总装重新生成了就把它们再打印。原11/12花键/铜套若已实测通过、来源和工艺没变，复用记录。

完整装配仍按 `README.md`，上述为验证/打印顺序，不是装配顺序。

## 1. 需要的实物

- 6200RS **10 × 30 × 9 mm，共3颗**；Pan两颗、Tilt一颗。核对实际品牌、密封圈和尺寸；不是6000、6800或6201。
- 两颗MKS-X8-HBL388，HERO8 Black；不改变真实舵机模型和装配耳孔。
- 螺钉/垫片/螺母按 `BOM.csv`、`FASTENERS.csv`。没有增加螺钉种类；原左压盖M2.5×8名义啮合5 mm。
- 热熔铜套仍为ruthex RX-M2.5x5.7。全机37颗，其中新重打件02/05/09/15需23颗，复用件内原有14颗保留。不要把不同商品的M2.5外形当相同。
- 卡尺、合适的热熔头、2 / 2.5 mm裸长臂内六角钥匙。需要量化回差时另备位移/角度测量装置。

## 2. 每一步的规则

1. 毫米单位、文件给定打印姿态；不要整体缩放、不要打印 `assembly_meshes/`。
2. 保持同材料、喷嘴与补偿参数；变化后相关实物配合记录不能直接复用。
3. 轴承压装只对相应圈施力，不通过滚珠传递压入力、不锤击。
4. 轴心螺钉不能用来把错误的花键/键连接硬拉进去；开缝不能被切片填死。
5. 不用大预紧抵消间隙；不能用强行回驱舵机判断轴承阻力。先脱开花键再测轻转阻力。
6. 发现裂纹、铜套转动、擦密封圈、异常阻力或偏轴就停止，记录实测值，针对失败接口修改；不整套缩放补救。

本版座孔Ø30.1 / 轴颈Ø9.98为**未实测的FDM起始值**，不是保证的配合公差。必要时只试一片 `T05_6200RS_seat_D30.1` 和一根 `T06_6200RS_journal_D9.98`；过紧/过松再换档，不要求所有试片都打。

## 3. 小件：17 / 07 / 14 / 18

- 17立放，8AF入口朝上，花键入口在底面。检查小孔顶桥接；支撑不得进入25T、8AF或开缝。
- 对齐25T，让17轻套真实Pan轴，再套旧06；检查端面止挡和静止凸台间隙。
- 07为Ø14.4 / Ø10.2 / 长3 mm，端面平整，只接触轴承内圈。
- 14为新Ø14.4内圈止口。实际检查止口不能接触橡胶密封；它不能先顶轴颈端部。
- 18**三个同文件**，Ø34 / Ø25.6 / 厚1 mm；不翘曲、不缺层、不用强预紧压弯。

通过条件：

- [ ] 新17真实齿形完整，正常就位，不摩擦舵机外壳。
- [ ] 旧06能套到17外圆并收紧，开缝未先完全闭合而仍松。
- [ ] 07/14只作用于内圈，18只作用于外圈；实物密封没有摩擦或压伤。
- [ ] 18数量为3，不漏装；其钢圈接触面完整平整。

## 4. 05可拆法兰轴

05的下端8AF公键和Ø9.98轴颈都能穿过闭合Ø10轴承；顶法兰和17接头不需要穿轴承。

先不接舵机，试两颗6200内孔、07、05/17键配合和旧06。再与真实Pan轴试接口。旧25T试配成功**不证明新8AF键已经通过**。

- [ ] 轴颈无明显椭圆、弯曲、象脚或锥度；不同高度均合适。
- [ ] 05/17键正常就位，端面贴合，未靠螺钉硬拉；夹紧后接口相对松动另测。
- [ ] 旧06收紧后没有先触及限位、没有层裂或铜套转动。
- [ ] M3×40 ISO7380-1实际不顶螺纹孔底；不把顶底误认成锁紧。

Pan的名义键侧隙为0.06 mm/面，未夹紧CAD总空行程约3.13°；旧25T约1.7°。**夹紧后能减少多少未实测；不能据此宣称高精度或零回差。** 无法分离舵机内部回差、花键、键和打印弹性时，记录“来源未分离”。

## 5. 15支架 / 旧13 / 18

新15孔Ø30.1、宽9 mm，从外侧放6200。18贴在轴承外圈外侧，再装旧13。旧13相对原总装向左5 mm，但形状和打印文件不变。

- [ ] 轴承正常就位、外圈不松摆。
- [ ] 18把旧13与密封/内圈隔开；固定后没有新增阻力或擦碰。
- [ ] 原M2.5×8正常锁紧，不顶孔、不被铜套拉出；工具可达。
- [ ] 支架铜套、环座、脚部与定位柱完整，无明显翘曲。

此时还不能宣称整个Tilt轴已经同轴或通过承载。

## 6. 09新笼架

这里只修改左轴颈长度和肩部：新轴颈完整支撑9 mm轴承，Ø14.4肩部与内圈接触。相机外廓、右法兰、11/12与10接口不变。

- [ ] 左轴颈完整、实际与6200内孔配合正常；不能只套入口。
- [ ] 14内圈顶帽未先顶轴端；名义轴端余量0.45 mm，实物另查。
- [ ] 原11和10能正常预装，相机夹持与取放正常。
- [ ] 独立热装7颗铜套后没有鼓包、歪斜、层裂或松动。

旧09短轴颈不是现版完整宽度支撑；不默认以“部分轴承套在轴上”代替重打。

## 7. 02完整Pan模块

1. 下轴承从下方入座；**轴承先放，再放下18和旧03**。
2. 07从上方放入，上轴承再入座，再装上18。
3. 旧04先从05下端套好，05/04从上方穿两轴承。
4. 17从下方接8AF键，旧06再从下方套17外圆。经法兰工具孔紧固04。
5. 未接舵机前检查轻转、窜动和阻力变化。不要让外径30轴承穿Ø25.6适配环。

- [ ] 两个Ø30.1座都合适，不能用一个通过代替另一个。
- [ ] 两个18均装齐，外圈有正确约束；05/07/17只作用于内圈。
- [ ] 名义0.15 mm内圈余隙实物核对，未靠强预紧消除间隙。
- [ ] 接合键、轴心、四孔工具通道和侧夹紧通道可达。
- [ ] 02环座、斜肋和安装柱无缺层、裂纹或桥接塌陷。

## 8. 用旧大件整装

沿README规定顺序复用01、16、08、11、12、10。先完整Pan模块和08，再预装Tilt笼架/花键、可卸左支架与轴承，相机最后放入。

- [ ] 舵机接插件、耳槽承托和原安装孔位正常，没有强迫对位。
- [ ] 左支架按抬高2.2 mm、从左滑入再下落的路线安装，不掰弯结构。
- [ ] 13已在新版向外位置，18装齐，总共3颗6200。
- [ ] 线缆有松弛环，不拉紧、不夹入、不把接插件当承力件。
- [ ] 无轴心顶底、接口松动、层裂、密封擦碰或新增阻力。

仅在供电、控制器和真实舵机行程确认后，从空载、小角度、低速低加速度开始。正常后再装HERO8做低载试验。CAD独立两轴±90°、每5°检查不是实机行程保证，也不是连续组合运动或线缆验证。

异响、卡滞、电流异常、发热、铜套转动、层裂或线缆拉紧时立即停机。**不做堵转，不把一次低载成功当成长期承载/精度验收。**

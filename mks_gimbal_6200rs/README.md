# MKS HBL388 + GoPro HERO8 双轴云台 · 6200RS 少重打版

**交付状态：CAD 数字装配 / FDM 试配原型。不是已试载、已测精度的成品。**

**当前版本：6200RS-MINREPRINT（2026-11-24）**，基于 LW1。所有现用轴承统一为 **6200RS，内径10 × 外径30 × 宽9 mm；Pan 两颗、Tilt 一颗，共三颗**。保留原底座、转台、相机中心、舵机安装孔和右侧 Tilt 传动接口。

**已经打印旧版的用户，只用 `reprint_only/stl/` 或 `reprint_only/3mf/`：6 个原有件重打，另加 2 种小件。18 适配环同一个文件打印 3 个。** 不要把整套 18 种文件再打印一遍。逐件兼容表见 [少重打清单与原因](REPRINT_GUIDE.md)。原 MKS / MG90S 目录不覆盖。

采用两颗真实 MKS-X8-HBL388、自打印真实 25T 接头。Pan 新增可拆 8AF 键连接，让闭合 Ø10 轴承能够套入；它不是齿轮副，但新增连接的回差仍须实测。打印件之间使用 M2.5 热熔铜套；舵机耳槽使用 M3 通栓和防转螺母。

## 先打开什么

- [少重打清单](REPRINT_GUIDE.md)：哪些原件可继续用、哪些必须换、18 的数量和原因。
- [新版 STL 打印验证流程](STL_PRINT_VALIDATION.md)：只针对变化的接口，复用仍有效的旧版实物记录。
- `reprint_report.json`：旧、新实际文件哈希对比；不是靠文件名判断兼容。
- `viewer.html`：离线交互查看器，双击即可；库和 GLB 已内嵌，不需要联网或启动服务器。可查看 Pan/Tilt、爆炸图、内部结构。
- `mks_gimbal.blend`：毫米单位的 Blender 总装。
- `mks_gimbal_exploded.blend`：爆炸视图。爆炸位移只是展示，不是安装路径。
- `renders/assembly_iso.png`：总装图；同目录有正面、侧面、爆炸图和 Pan 内部视图。
- **打印用 `3mf/` 或 `stl/`。不要打印 `assembly_meshes/`，后者是总装坐标。**

3MF 是带毫米单位和打印姿态的**模型文件**，不含已调好的打印机、材料、支撑或 G-code 预设。

## 必须先试配，避免整套打印浪费

1. 旧 11/12 若已通过实物试配且打印条件不变，不必重打这些件或原 T01–T04。新 17 仍须与真实输出轴、旧 06 和新 05 单独试配。未验证过花键时，可先用 T02；过紧/过松再试 T01 / T03。
2. 打印 T04，试 ruthex **RX-M2.5x5.7** 的 3.8 / 4.0 / 4.2 mm 热熔底孔。本版暂用 Ø4.0、深 6.2 mm。
3. 本版两轴轴承座均为 Ø30.1，轴颈均为 Ø9.98 mm。必要时先试 `T05_6200RS_seat_D30.1` / `T06_6200RS_journal_D9.98`；不要求把所有尺寸试片都打印。不要靠锤击解决误差。
4. 先试小件 17、07、14、18 与实际轴承；再打印 02、09、15。18 只应接触钢制外圈，14 / 17 / 05 的 Ø14.4 止口只应作用于内圈，不碰橡胶密封。

**重要精度限制：** 原真实 25T、0.06 mm 齿面放大量不变，未夹紧 CAD 空行程约1.7°。Pan 还新增 8AF 可拆键，其未夹紧接触角见 `assembly_checks.json/pan_detachable_key`。夹紧后的回差没有实测；不能宣称零回差。先验证小件，不以增大拧紧力补偿错误配合。

厂商尺寸图的 **M3 指输出轴中心螺纹**。安装耳是 R2 开口槽，不是已确认的 M3 螺纹孔。本版用 M3 通栓 + DIN934 防转螺母固定安装耳，**不拆、借用舵机壳体原有螺钉**。官方 Gear Mount 只作为原始参考保留，不用于传动。

有效内圈接触外径统一为 Ø14.4，外圈适配环内孔为 Ø25.6。依据具名 SKF 6200-2RSH 目录：轴肩直径14.2–15.0，座肩孔径最大25.8 mm。**用户轴承品牌、RS/2RS密封数和实际肩部尚未提供；这里只确认6200的10×30×9名义外廓，仍须核对实物密封与端面。** 不把未知品牌等同于 SKF，也不把孔径补偿当已实测公差。

### 一个轴是否可以只用一颗轴承？

- **Tilt：可以沿用一颗外置轴承。** 相机一端由6200RS支撑，另一端由舵机输出轴支撑，不是整根轴只有一个支撑点；舵机侧载能力仍未试验。
- **Pan：本版保留两颗。** 单颗单列深沟球轴承不应按独立抗倾覆支撑使用；省去一颗会更多依赖舵机输出轴、壳体、打印座的刚度与侧载能力。仅有轻相机也不能证明冲击、偏心或线缆拉力下可靠。
- 本版不另做未经试载的单轴承 Pan，也不要求购买其他轴承型号。如果只有两颗6200RS，应先确认载荷与可接受的晃动，再决定是否另作轻载方案。

## 装配顺序（不能随意省略）

1. 在独立打印件上热装全部铜套，冷却后检查不歪、不转、不顶出。数字工具空间使用 Ø8 × 22 mm 细头、Ø16 mm 外壳包络；你的实物烙铁仍需确认。
2. 放入 01 和 16 的 M3 防转螺母。16 暂不安装，把 Pan 舵机从上方放入开放底座，再把 16 从前侧滑入左安装耳下方。用四颗 M2.5×10 锁安装桥，再用四颗 M3×10 + 垫片固定舵机耳。
3. 独立装Pan模块：下轴承从下方入座；再从下方放一片18，安装旧03。07从上方放入，上轴承从上方入座；然后从上方放第二片18。**不要先装18再让外径30的轴承穿过其Ø25.6孔。**
4. 旧04先从05的下端套好，再将05/04从上方穿入两轴承。对齐8AF键，从下方将17套到05；旧06再从下方套到17外圆。经法兰四个工具孔紧固04；不要用压盖强拉内圈，也不要强预紧。17与05的键必须正确就位，不能用轴心螺钉硬拉。
5. 将预装模块的17轻套到Pan真实25T轴上。从四个深工具孔锁到01；拧原规格Pan轴心M3×40。确认17的端面止挡、05/17键贴合且不摩擦舵机凸台，再从侧窗口轻紧旧06。名义内圈堆叠余隙0.15 mm，实物窜动与阻力必须检查。
6. 转台 08 锁到 Pan 法兰，**此时笼架还未放入**。从右侧穿入 Tilt 舵机，放入防转 M3 螺母并锁紧四个安装耳。
7. 在支架外先用四颗 M2.5×6 把 11 锁到 09，再从花键端套入 12。四颗法兰螺钉在装上夹紧套 / 舵机后不好接近，必须先预装。
8. **15 左支架尚未安装。** 笼架 / 轴套组合向右套入真实花键，经笼架右侧中心工具孔拧 Tilt 轴心 M3×8；相机此时必须取出。再紧夹紧套。
9. 不带轴承的 15 抬高约 2.2 mm，从左侧沿轴线滑入，再下落使两个定位柱入槽；四颗 M2.5×10 锁到转台。该路线已数字采样核验，实物应无强行掰弯。
10. 从左侧套入6200RS；第三片18从外侧贴住外圈，再装旧13（外移5 mm位置）。原M2.5×8仍可用，名义铜套啮合5 mm。再装新14及原M2.5×10+垫片；14与新轴颈端仍留0.45 mm名义余量。先脱开花键检查轴承自由转动，不强行回驱舵机。
11. 加泡棉后从上方放入 HERO8，折叠安装脚，装 10 顶压条。名义压缩后下 / 后 / 两侧间隙为 0.5 mm，顶垫约 1.5 mm。泡棉厚度和握持力要实物调整，不能挤压按钮或屏幕。

实际按钮、USB / 电池门触达未验证；换电池 / 接线建议取出相机。首次运动从小角度、低速度开始，留线缆松弛环；模型里的 ±90° 不是舵机电气行程保证，也不包括真实线缆扫掠。

## 已验证 / 未验证

输出网格、打印姿态、3MF毫米单位、实际接收孔、轴颈、铜套周壁与工具通道的检查结果见 `quality_report.json`、`assembly_checks.json`。其中10个原有打印文件按实际SHA256复用，13只有刚体位移；18的三个装配实例共用同一打印文件。

总装进行了打印件 / 原始舵机 / 紧固件体积干涉检查；Pan、Tilt 各从 -90° 到 +90°、步长 5° 的采样无超过 0.05 mm³ 的非预期体积干涉。允许铜套热熔材料置换和螺纹啮合，未把它们误算为碰撞。

规定顺序的舵机、预装模块、安装桥、左支架、轴承、相机、防转螺母的安装路径，以及紧固工具通道均做了数字检查。正向压入 0.10 mm 的止挡试验确认：先遇到输出轴端面止挡，未撞静止舵机外壳。

**未完成：** 实际切片、FDM 试配、铜套拉拔、长期蠕变、夹紧后回差、承载 / 冲击、振动、热稳定性、电气控制与真实线缆验证。**不保证承受舵机满堵转扭矩，不做堵转试验，不给未经试验的拧紧扭矩或精度指标。**
